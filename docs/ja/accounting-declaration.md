# 付録B　会計処理に関する重要な宣言

Pレンズは、遊技に伴う金銭的な負担を軽視しない。

遊技の収益及び費用を記録する。

遊技媒体の取得及び消費を記録する。

店舗ごとの貯玉及び貯メダルを記録する。

必要に応じて、交換条件、評価差額及び各種調整を記録する。

特殊景品及び端玉景品の取得も記録する。

しかし、記帳には境界がある。

記録しない事象について、帳簿は沈黙する。

その沈黙は、現実の否定ではない。

単なる、会計モデルの境界である。

以上。
