# Pレンズ遊技会計基準

― 遊技に伴う経済事象の記録及び景品交換に関する会計方針 ―

P-Lens Accounting Standards（PLAS）

- 版：第1.0.2版
- 制定日：2026年10月13日
- 改正日：2026年10月21日
- 適用範囲：Pレンズ及びその会計モデルを利用する者
- 基準通貨：日本円並びに店舗固有の玉及びメダル
- 基本原則：貸借一致、記録の誠実性、景品交換以後の沈黙

## 前文

Pレンズ（以下「本システム」という。）は、ぱちんこ遊技機及び回胴式遊技機による遊技に伴う経済事象を、複式簿記の原理に基づき記録することを目的とする。

従来、一般的な家計簿においては、これらの経済事象は「パチンコ -12,000円」の一行をもって処理されてきた。

しかしながら、遊技の過程においては、金銭の投入、遊技媒体の取得及び消費、賞球の獲得、貯玉、景品交換等、性質の異なる多様な経済事象が発生している。

本基準は、これらの経済事象を合理的かつ継続的に記録するための統一的な取扱いを定めるものである。

なお、本基準は、遊技施設における景品交換を超えて経済事象を追跡することを目的としない。

記帳には境界がある。

本基準は、その境界を明確にするものである。

## 第1章　基本原則

### 第1条（会計の目的）

1. 本基準は、遊技に伴う費用及び収益並びに遊技媒体及び景品の取得を、統一的な方法により記録することを目的とする。

2. 記帳は複式簿記によるものとし、貸借の一致を原則とする。

3. 貸借の一致は、記録された事実の正確性を保証するものではない。

4. 遊技者が虚偽の情報を入力した場合、本システムは、当該虚偽を極めて正確に記録する可能性がある。

5. 前項の場合において、hledgerは責任を負わない。

### 第2条（記録の誠実性）

1. 記録は、実際に観測された事実に基づいて行うものとする。

2. 推定値と観測値とは区別して記録し、不明な事実を既知のものとして取り扱ってはならない。

3. 帳簿上の残高と現実の残高とが一致しない場合には、合理的な方法により帳簿を調整するものとする。

4. 帳簿を正しくすることを目的として、現実の玉数を変更してはならない。

### 第3条（店舗固有通貨）

1. 遊技媒体は、店舗及び貸出単価の別に、それぞれ独立した数量単位として管理する。

2. A店の125玉とB店の125玉とは、数量が一致することのみをもって同一の資産とみなしてはならない。

3. 前項の区別を怠った場合、帳簿上は十分な玉数を保有しているにもかかわらず、目の前の遊技機には一玉も投入できない事態が生じ得る。

4. 本基準は、前項の事態を流動性の著しい欠如として取り扱うことを妨げない。

## 第2章　費用及び収益

### 第4条（遊技費用）

1. 遊技媒体の消費に伴う経済的負担は、所定の費用勘定に計上する。

2. 費用の認識は、遊技者の感情から独立して行う。

3. 遊技者が「今日は実質勝ち」と主張した場合であっても、当該主張をもって費用を減額してはならない。ただし、「楽しかったから勝ち」という精神的満足そのものを否定するものではない。

### 第5条（遊技収益）

1. 遊技により獲得した経済的価値は、所定の収益勘定に計上する。

2. 収益の認識は、実際に発生した事象に基づいて行う。

3. 隣席の遊技者に大当りが発生した事実を、自己の収益として計上してはならない。

4. 前項の規定は、特に厳格に適用する。

### 第6条（現金の取扱い）

1. 遊技に投入した現金は、これを記録する。

2. 遊技者が申告する回収額は、遊技の結果を集計するための観測情報として取り扱うことができる。

3. 前項の規定は、景品交換後の現金取引を本システムが記帳することを意味するものではない。

4. 数値を把握することと、当該数値に至るすべての取引を記帳することとは、別個の問題である。

### 第7条（現金に関する片方向性）

1. 本システムは、遊技施設における遊技から景品交換までを記帳の対象とする。

2. 景品取得後の経済活動は、本システムの管理対象外とする。

3. 現金勘定は、遊技への投入により減少することがあるが、本システムが作成する仕訳により増加することはない。

4. 本システムは、特殊景品を現金に変換する仕訳を、標準の取引モデルに設けない。

5. 前二項の規定は、景品取得後に現実世界において発生する経済事象の存在を否定するものではない。

6. 本システムは、記帳の対象外とした事象について判断を行わない。

7. 前項の判断を行わないことについて、追加の判断も行わない。

8. 知らないこととしているのではない。記帳しないのである。

9. 前項の区別は、本基準において極めて重要である。

## 第3章　景品

### 第8条（景品の会計処理）

1. 遊技媒体を景品に交換した場合には、当該交換をもって、当該遊技媒体に関する記帳を終了する。

2. 交換払出に係る遊技媒体は、特殊景品に交換したもの及び特殊景品との交換に満たない残余（以下「端玉」という。）に区分し、それぞれ次条及び第10条に定める終端勘定に計上する。

3. 前項の計上は、景品交換時における評価額をもって行い、遊技者が景品を現実に受領したか否かを問わない。

4. 第2項の終端勘定は、本システムに固有の管理会計上の分類であり、一般的な財務会計における純資産の定義を変更するものではない。

### 第9条（特殊景品）

1. 特殊景品に対応する終端勘定は、次のとおりとする。

   `純資産:特殊景品`

2. 前項の勘定は、特殊景品の取得をもって遊技に関する記帳が終了したことを表示するための、本システムに固有の管理会計上の勘定であり、一般的な財務会計における純資産の定義を変更するものではない。

3. 特殊景品を現金そのものとして取り扱ってはならない。

4. 特殊景品が特殊である理由については、本基準において詳細な定義を設けない。

5. 少なくとも、一般景品と区別して管理すべき事情が存在することは、これを認める。

6. 特殊である。

### 第10条（端玉景品）

1. 端玉は、景品交換時に終端処理し、その評価額を次の終端勘定（以下「端玉景品勘定」という。）に計上する。

   `純資産:端玉景品`

2. 端玉景品勘定は、景品交換時に終端処理された端玉の評価額を記録するものであり、景品の現実の受領を要件としない。

3. 例えば、交換率3.57円の店舗において1,405玉を交換払出し、1,400玉をもって5,000円分の特殊景品を取得し、5玉が端玉として残った場合、店舗は当該5玉に相当する一般景品としてラムネ2個を提示する。このとき、当該景品の受領を辞退する遊技者は少なくない。この場合においても、5玉の評価額は端玉景品勘定に計上する。

4. 前項の場合において、ラムネは店舗に残り、端玉は帳簿から去る。本システムは、その後のラムネの行方を追跡しない。

5. 端玉に代えて受領する一般景品には、菓子、飲料、食品、日用品その他の物品を含み、ラムネについても同様とする。

6. 景品の市場価格と交換時の評価額とが一致しない場合であっても、そのことのみを理由として端玉景品勘定に計上する額を変更してはならない。

7. 15玉相当の景品として受領した飲料が近隣の小売店においてより安価に販売されていることは、本基準における重要な会計上の問題としない。ただし、遊技者が不満を抱くことを妨げない。

### 第11条（景品の高級化）

1. 遊技者が通常より高価な一般景品を取得した場合についても、前条の規定を適用する。

2. 景品が菓子であるか、家庭用品であるか、その他の物品であるかにより、終端勘定の基本的性質は変化しない。

3. 本基準は、ヤクルト等と高級菓子との間に、会計上の身分制度を設けない。

4. すべての一般景品は、原則として平等に終端処理される。ただし、景品そのものの価値が等しいことを意味するものではない。

### 第12条（景品交換の終端性）

1. 本システムは、景品取得後の保管、消費、譲渡その他の経済活動を追跡しない。

2. 特殊景品についても、取得後の取引は記帳の対象外とする。

3. 前二項の規定は、現実世界における経済事象の存在を否定するものではない。

4. 景品の取得をもって記帳を終了することは、本システムの会計モデルにおける意図的な境界である。

## 第4章　換算及び調整

### 第13条（換算調整勘定）

1. 遊技媒体の換算額と景品の評価額との間に生じる1円未満の端数その他の遊技媒体の評価及び換算に伴う差額は、所定の方法に従い、次の勘定により調整することができる。

   `純資産:換算調整勘定`

2. 前項の勘定は、複数の数量単位を取り扱うことに伴う帳簿上の整合性を確保するために設ける。

3. 換算に伴う差額は、遊技者の勝敗と当然に一致するものではない。

4. 数値が一致しない理由を明らかにしないまま、すべての差額を第1項の勘定に計上することは、推奨しない。

5. 第1項の勘定は、帳簿の不整合を無条件に隠蔽するための便利な箱ではない。ただし、勘定科目の名称が極めて立派であることは、これを認める。

### 第14条（端数処理）

1. 端数処理は、各店舗の取扱条件及び記帳上の必要性に応じ、適切な方法により行う。

2. 端数が生じた場合には、必要な調整を行う。

3. 端数を無視することができるか否かは、その性質及び金額的重要性に照らして判断する。

4. 端数であることは、存在しないことを意味しない。

5. 端玉が存在する以上、端玉景品もまた存在し得る。

6. 端玉景品が存在する以上、ヤクルトが純資産となる可能性もまた存在する。

7. 本条は、第10条の規定を補強するものである。

## 第5章　推定

### 第15条（期待値の取扱い）

1. 期待値は、一定の確率モデル及び算出条件に基づいて算出される理論値である。

2. 期待値が正であることは、個別の遊技における利益を保証するものではない。

3. 観測情報が不足する場合、本システムは、確率的な推定を行うことができる。

4. 計算回数を増加させたことのみをもって、観測されていない事実が判明することはない。

## 第6章　会計エンジン

### 第16条（hledgerの尊重）

1. 本システムは、会計処理の中核としてhledgerを利用する。

2. hledgerが提供する会計機能については、合理的な理由がある場合を除き、独自の重複実装を行わない。

3. 本システムに固有の会計方針は、標準的な会計理論及びhledgerの機能と区別して管理する。

4. hledgerの開発者が本基準に定める景品の会計処理を想定していたか否かについて、本委員会は確認していない。

5. 確認していないことについて、深い敬意を表する。

### 第17条（利用者に求める知識）

1. 利用者に対し、複式簿記、Haskellその他のプログラミング言語に関する知識を要求しない。

2. 本基準が存在することを知らない利用者であっても、支障なく記帳できることを目標とする。

## 第7章　雑則

### 第18条（本基準の優先順位）

1. 本基準の運用に当たっては、次に掲げる事項を重視する。

   1. 実際の記録に基づくこと。
   2. 帳簿の整合性を確保すること。
   3. 推定と事実とを区別すること。
   4. 利用者に不要な複雑さを負担させないこと。
   5. 景品取得後の経済活動を無用に追跡しないこと。

2. 前項各号に掲げる事項は、相互に整合するよう解釈しなければならない。

### 第19条（記帳の範囲及び責任）

1. 本システムは、遊技に関する経済事象を記録するためのものであり、遊技による利益を保証するものではない。

2. 記帳が極めて正確であったことを理由として、現実の損失が軽減されることはない。

3. 本基準は、一般に公正妥当と認められる企業会計の基準及び税務上の取扱いに代わるものではない。

4. 利用者は、本基準の取扱いと一般的な財務会計上の分類とが異なることを理解した上で、本システムを利用するものとする。

## 附則

### 第1項（制定及び適用）

本基準は、本システムにおいて適用される会計モデルを説明する文書として制定し、2026年10月13日から適用する。

### 第2項（一般的な会計基準との関係）

本基準は、本システムに固有の管理会計上の取扱いを定めるものであり、日本の企業会計基準、税務上の取扱いその他の公的な会計基準に代わるものではない。特に、景品を「純資産」に計上する方法は、本システムが採用する独自の終端処理であり、一般的な財務会計における景品の資産分類を否定するものではない。

### 第3項（改正）

本基準は、利用者の実態、ソフトウェアの仕様及び会計処理上の必要性に応じて改正することができる。ただし、改正に当たっては、記録済みの帳簿との整合性及び過去の会計処理との継続性に十分配慮するものとする。

### 第4項（景品の事後管理）

本基準の改正は、過去に取得した景品について、遡及的な棚卸しを要求するものではない。既に飲用されたヤクルトについても、同様とする。
